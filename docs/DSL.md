# 简谱 DSL 语法参考

> 适用于 `music-preprocessor-py` 工具。
> 一句话：**用空格分隔的简谱记号 + 若干 `Xxx:` 声明**，`|` 分小节，一行写完一首也行。

## 速查卡

```text
Title:小星星            % 头部信息（整行）
Key:C Time:4/4          % 调号 / 拍号（必须）
Tempo:4=100             % 速度（可选）

H: 一闪一闪亮晶晶        % 汉字歌词，一字一音（H1:/H2: 指定段号）
[C] 1 1 [G7] 5 5 | [Am] 6 6 [D7] 5 - |
q1 q2 q3 q4
```

| 记号 | 含义 |
|---|---|
| `1`…`7` | 音级（do…si） |
| `0` / `x` | 休止 |
| `8` / `9` | `1'` / `2'` 的简写（高八度） |
| `'` / `,` | 升/降八度（可叠：`1''`） |
| `#` / `b` | 升/降半音，写在音级前：`#4`、`b7` |
| `.` | 附点，写在最后：`1.` |
| `-` | 延长一拍（可连写） |
| `~` | 连音线（到下一个音） |
| `(` `)` | 圆滑线起/止（贴在前一个音后；也可贴写成 `(2`、`2)`） |
| `[C]` | 和弦，作用于**下一个**音 |
| `\|` | 小节线；`\|\|` 双小节线 |
| `q` `s` `d` `c` `h` | 时值前缀：八分、十六分、三十二分、四分、六十四分 |
| `\break` | 换行（放在某个音后面） |
| `^"文字"` / `_"文字"` | 谱上文字（上/下） |
| `%` | 注释到行尾 |

---

## 1. 文件结构

- 记号之间用**空白**分隔（空格、Tab、换行都行），换行不表示音乐含义。
- 但有三类是**整行**语法，必须写在行首、独占一行：
  - 头部信息 `Title:` `Subtitle:` `Composer:` …
  - 歌词 `H:` `L:`
  - 原样 LilyPond 块 `LP: … :LP`
- `%` 开头到行尾是注释。

```text
% 这是注释
Key:C Time:4/4
1 2 3 4 | 5 6 7 1' |
```

## 2. 头部信息

| 字段 | 说明 | MusicXML/MuseScore |
|---|---|---|
| `Title:` | 标题 | 标题 |
| `Subtitle:` | 副标题 | 副标题（与 Subsubtitle 合并成一行） |
| `Subsubtitle:` | 次副标题 | 同上 |
| `Composer:` | 作曲 | 右上角 |
| `Poet:` | 作词 | 左上角 |
| `Instrument:` | 乐器/说明 | 目前忽略（LilyPond 会写进 header） |
| `Arranger:` `Copyright:` | 编曲/版权 | 目前忽略 |

- 字段名**大小写敏感**，冒号必须是半角 `:`。
- 值取该行冒号后的全部内容，可以带空格和中文。

```text
Title:小星星
Subtitle:带和弦的 Lead Sheet
Composer:曲：传统
Poet:词：佚名
```

## 3. 调号、拍号、速度

```text
Key:C  Key:G  Key:F#  Key:Bb  Key:Am  Key:F#m
Time:4/4  Time:3/4  Time:6/8  Time:2/2
Time:3/4,4          % 弱起：3/4 拍，弱起 1 拍（4 = 四分音符，8 = 八分）
Tempo:4=100         % 四分音符 = 100
```

- `Key:` 和 `Time:` **必须有**，缺了会报错。
- 三个声明可以写在任意位置、也可以和音符写在同一行（`Key:C Time:4/4` 常见写法）。
- 同一文件里重复声明时，**后写的生效**（作用于整首）。

**支持的调**（大调 15 个、小调 15 个）：

```text
大调：C G D A E B F# C#  F Bb Eb Ab Db Gb Cb
小调：Am Em Bm F#m C#m G#m D#m A#m  Dm Gm Cm Fm Bbm Ebm Abm
```

> 小调按「关系大调」的音阶取音，`Key:Am` 里的 `1` 是 A。

## 4. 音符

一个音符记号的完整形式：

```
[时值前缀] [升降号] 音级 [八度记号] [附点]
   q/s/d/c/h   #/b    0-7/8/9/x   ' 或 ,     .
```

例：`q#4'` = 八分音符、升四级、高八度；`b7,` = 降七级、低八度；`1.` = 附点四分。

### 4.1 时值前缀

| 前缀 | 时值 | 4/4 中占几拍 |
|---|---|---|
| （不写） | 四分音符 | 1 |
| `c` | 四分音符（显式写出） | 1 |
| `q` | 八分音符 | 1/2 |
| `s` | 十六分音符 | 1/4 |
| `d` | 三十二分音符 | 1/8 |
| `h` | 六十四分音符 | 1/16 |

大小写都行（`q` 和 `Q` 等价）。

### 4.2 音级

| 记号 | 含义 |
|---|---|
| `1`–`7` | 调内音级（首调唱名 do–si） |
| `0` | 休止 |
| `x` / `X` | 休止（与 `0` 相同，写法来自打击乐） |
| `8` | `1'` 的简写 |
| `9` | `2'` 的简写 |

### 4.3 八度

`'` 升一个八度，`,` 降一个八度，可以叠写：

```text
1      中音区（C 调是 C4；G 调是 G3；Bb 调是 Bb3）
1'     高八度（Bb 调 = Bb4）
1''    高两个八度
1,     低八度
```

`1` 默认放在**中央 C 附近**（上下不超过 6 个半音），音级从本调主音往上数，
所以 `1 2 3 4 5 6 7` 在任何调里都往上走：

```text
Key:C   C4  D4  E4  F4  G4  A4  B4
Key:G   G3  A3  B3  C4  D4  E4  F#4
Key:Bb  Bb3 C4  D4  Eb4 F4  G4  A4
```

### 4.4 升降号

只支持单个 `#` 或 `b`，写在音级**前面**、时值前缀**后面**：

```text
#4    升四级
b7    降七级
q#4'  八分、升四级、高八度
```

升降号是**在调号基础上**再加的：`Key:G` 时 `4` 本来就是 C，`#4` 得到 C♯。

### 4.5 附点

结尾一个 `.`，时值 ×1.5。**只支持单附点**：

```text
1.   附点四分（1.5 拍）
q3.  附点八分
```

## 5. 延长、连音线、圆滑线

### 延长 `-`

每个 `-` 让**前一个音**多响一拍（四分音符的时长），与它原本的时值无关：

```text
1 -        2 拍
1 - -      3 拍
1 - - -    4 拍（整小节）
q1 -       0.5 + 1 = 1.5 拍
```

### 连音线 `~`

把前一个音连到下一个音（用于跨小节、跨拍）：

```text
1 ~ 1 3       第一个 1 连到第二个 1
1 ~ | 1 2 3   跨小节连音
```

### 圆滑线 `(` `)`

两种写法等价：

```text
4 ( 5 ) 6      括号分开写：( 贴在 4 后面，表示 4→5 一条圆滑线
(4 5)          括号贴写：(4 表示从 4 开始，5) 表示到 5 结束
```

注意：分开写时 `(` 是**从前一个音开始**，所以 `4 ( 5 )` 连的是 4→5，不是 5→下一个。

## 6. 和弦

`[和弦名]` 写在音符**前面**，绑定到紧跟的那个音：

```text
[C] 1 1 [G7] 5 5 | [Am] 6 6 [D7] 5 - |
```

和弦名基本是**透传**的（大调字母 + 后缀），常见写法都支持：

```text
[C] [Am] [G7] [Cmaj7] [Cm7] [Dm9] [G13] [C6/9]
[F#m7b5] [Bb] [Eb] [C/E] [G7sus4] [A7]
```

> - `C/E` 这种斜杠和弦：斜杠后面必须是音名，否则会当成和弦后缀（`C6/9` 的 `/9` 不会被误判）。
> - MuseScore 会把自己的和弦符号规范化一下，例如 `G7sus4` 显示成 `G7sus⁴`，含义不变。
> - 一个 `[C]` 只作用于下一个音；中间隔了休止也一样。

## 7. 歌词

| 写法 | 规则 |
|---|---|
| `H: 一闪一闪亮晶晶` | 汉字歌词，**一个字一个音**，标点自动贴到前一个字上 |
| `L: twin-kle twin-kle` | 拉丁歌词，按**空格**切分音节 |
| `H1: …` / `H2: …` / `L1: …` | 指定第几段（数字 1–9） |

### 基本用法：几段就写几行

```text
H1: 春天来了花儿开
H2: 秋天到了果实熟
```

`H1` 在上面、`H2` 在下面；两段共用同一条旋律。

### 歌词从哪儿开始

**写在某行音乐下面的歌词，就属于那一行音乐**，从那一行的第一个音开始唱：

```text
[Bb] 0 q1 q2 q3 q5 q6 q3 | ...     % 第 1 小节，第 1 拍是休止
H: 我们成为一家人……                % → 「我」落在第 1 小节第 2 拍
```

- 同一段歌词**可以拆成好几行**写（长句换行），会自动接着上一行往下排
- 同一行里也能切换段：`H: 耶稣，成为神国的子民。H1: 因着耶稣得洁净，`
- 老写法 `H: 1. 春天…` / `H: 2. 秋天…`（行首写 `1.` 或 `1．`）等价于 `H1:` / `H2:`，仍然可用

### 从中间开始分两段

新的一段（`H2`）从**上一条歌词的起点**开始 —— 也就是和上一段**对齐到同一段音乐**：

```text
...
H: 耶稣，成为神国的子民。H1: 因着耶稣得洁净，   ← H1 接着「子民。」唱
H2: 因着耶稣同敬拜，                             ← H2 也从「子民。」后面开始
```

所以副歌两段唱的是同一段旋律，上下两行对齐。

### 细节

- 歌词按顺序贴到**每个唱的音**上；文字不够时后面的音就不带歌词，多了会截掉
- **延音线后面的音不再占字**（`q2' ~ | 2'` 是一个唱音），所以 `97 个音 - 5 个延音 = 92 个字`
- `_` 表示**并字**：把下一个字并到前一个字上，两个字唱同一个音，例如 `H: 啦_啦`
- 段号只是数据，MuseScore 默认不打印 “1.” “2.” 这两个数字

## 8. 小节线与排版

**源文件里怎么换行，谱面上就怎么换行**：一行音乐 = 一行谱（一个 system）。
想要某一行特别长/特别短，直接在源文件里调整换行即可。

| 写法 | 作用 |
|---|---|
| `\|` | 小节线（行尾可以省略） |
| `\|\|` | 双小节线（段末常用），也支持 `\|.` `.\|` `\|:` `:\|` |
| （换行） | 源文件换行 = 谱面换行 |
| `\break` | 强制换行（和直接换行等价，写在某个音后面） |
| `\bar "\|\|"` | 和 `\|\|` 等价，LilyPond 原生写法 |
| `^"文字"` | 音符上方的文字 |
| `_"文字"` | 音符下方的文字 |

```text
[C] 1 2 3 4 \break | [G7] 5 6 7 1' |
1' ^"副歌" 7 6 5 |
```

- 每小节的实际拍数最好和拍号一致；不一致时 MusicXML 后端会给 warning（MuseScore 仍能打开，但会补休止）。
- 连续的 `|` 不会产生空小节。

## 9. 原样 LilyPond

只有用 `-f ly` 输出时才有意义；转 MusicXML 时会**忽略并 warning**。

```text
LP:
\paper { top-margin = 20\mm left-margin = 20\mm }
:LP
```

- `LP:` 与 `:LP` 之间的内容原样塞进 `.ly` 文件顶层。
- 以 `\` 开头的记号、`^"…"`、`_"…"`、`"…"` 会**贴在前一个音后面**原样输出。
- 转 MusicXML 时只认得 `\break`、`\bar "…"`、`^"…"`、`_"…"`，其余给 warning 后丢弃。

## 11. 还没实现 / 会报错

| 写法 | 现状 |
|---|---|
| `R{ … }` 反复 | 报错：`repeat/alternate notation not supported yet` |
| `A{ … }` 跳房子 | 同上 |
| `-` 前面没有音 | 报错：`'-' dash must follow a note` |
| `~` `(` `)` 前面没有音 | 报错 |
| 缺少 `Key:` 或 `Time:` | 报错：`No Key: declaration found` |
| 未知调名（如 `Key:H`） | 报错：`Unknown key 'H'` |

## 13. 命令

```bash
python mpp.py song.dsl                    # 默认出 MuseScore 工程 song.mscz
python mpp.py song.dsl -f pdf             # 打印版
python mpp.py song.dsl -f mscz,pdf        # 一次出两种
python mpp.py song.dsl -f musicxml        # MusicXML
python mpp.py song.dsl -f ly              # LilyPond 源码（legacy，打到 stdout）
```

Windows 下也可以 `mpp.cmd song.dsl -f pdf`。

参数：`-f`（`mscz`（默认）\| `pdf` \| `png` \| `musicxml` \| `ly`，可逗号组合）、`-o`、`--musescore`、`--style`、`--no-style`、`--keep-xml`、`-q`。
